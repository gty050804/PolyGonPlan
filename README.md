# 多边形连线对战游戏

本项目实现了一个在平面上连接 15 个圆环、围住彩色点数取分的几何对战游戏，包含：

- `polygon_server.py`：双人对战版本（局域网内两台设备或一机双开）。
- `polygon_ai_server.py`：人机对战版本（本机玩家 vs 虚拟对手 AI），支持简单 / 普通 / 困难三档难度。
- 前端页面共用 `static/polygon.html`。

---

## 基本规则（双人 & 人机通用）

- 画布上随机分布：
  - 16 个白点（+1 分）、8 个蓝点（+2 分）、2 个绿点（+5 分）、4 个红点（-4 分）；
  - 15 个黑色空心小圆环（只允许在圆环圆心之间连线）。
- 每局 5 分钟，**5 局 3 胜**：
  - 玩家在每局内，通过依次点击两个圆环，在它们之间连线 / 断线；
  - 目标是在 5 分钟内用 15 条线段把 15 个圆环首尾连成一个**不自交的 15 边形回路**；
  - 验证通过后，统计 15 边形内部所有彩色点的得分：
    - 白点：+1 分
    - 蓝点：+2 分
    - 绿点：+5 分
    - 红点：-4 分
  - 若只有一方在时限内完成合法 15 边形，则该方本局胜；
  - 若双方都完成，比较本局得分，高分者本局胜；
  - 若本局得分相同，则以**提交用时更短者**本局胜。
- 整场比赛采用「5 局 3 胜」，先获得 3 局胜利的一方赢得整场。

## 环境准备

建议使用虚拟环境：

```bash
pip install -r requirements.txt
```

## 一、双人对战（`polygon_server.py`）

1. 启动服务端：

   ```bash
   python polygon_server.py
   ```

   默认监听 `http://0.0.0.0:5001`。

2. 两名玩家分别在浏览器中访问：

   - 本机：`http://localhost:5001`
   - 局域网其他设备：`http://你的电脑IP:5001`

3. 大厅中每位玩家：

   - 输入自己的昵称（可选，不填则为「玩家1/玩家2」）；
   - 点击「玩家 1」或「玩家 2」加入；
   - 两人都加入后自动开始第 1 局。

4. 每局结束后，双方会看到：

   - 本局胜负结果；
   - 双方题板（15 边形 + 所有点）；
   - 各颜色点数量与本局得分；
   - 当前总胜场数；
   - 点击「准备下一轮」后，下一局开始。

5. 当一方先拿到 3 局胜利时，显示整场结果以及最后一局的题板与统计。

---

## 二、人机对战（`polygon_ai_server.py`）

1. 启动人机对战服务端：

   ```bash
   python polygon_ai_server.py
   ```

   默认监听 `http://0.0.0.0:5002`。

2. 在浏览器访问：

   ```text
   http://localhost:5002
   ```

3. 大厅中：

   - 输入自己的昵称（可选）；
   - 选择难度：
     - 简单（easy）：AI 只做少量搜索，给出较优但明显不完美的解；
     - 普通（normal）：AI 搜索更久，但故意使用「次优解」，强但不是最强；
     - 困难（hard）：AI 使用较长时间搜索最优解，但提交用时被设置为 100~250 秒，玩家在分数持平时仍有机会凭用时取胜；
   - 点击「玩家 1」或「玩家 2」按钮之一加入（人机模式下两者等价）。

4. 之后流程与双人模式基本相同，只是对手为昵称固定为 `AI` 的虚拟玩家，每局和整场结束时都会显示难度标签。
