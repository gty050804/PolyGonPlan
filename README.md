# 双人答题对战

双方玩家各看到一块题板，**题目由服务器统一发出，保证两人题目相同**。题型为 4 位数加减法 或 2 位数乘法，每题 1 分钟内作答正确得 1 分，错误则该题作废进入下一题，共 10 题，得分高者获胜。

## 运行方式

1. 安装依赖（建议使用虚拟环境）：
   ```bash
   pip install -r requirements.txt
   ```

2. 启动服务端：
   ```bash
   python server.py
   ```
   服务会在 `http://0.0.0.0:5000` 启动。

3. 两名玩家分别打开浏览器访问：
   - 本机：`http://localhost:5000`
   - 同一局域网内另一台设备：`http://你的电脑IP:5000`

4. 一人点击「玩家 1」，另一人点击「玩家 2」。两人都加入后自动开始，双方会同时看到同一道题，在 1 分钟内作答并提交，得分高者获胜。

## 规则摘要

- 题型：随机 4 位数加减法（如 `1234 + 5678 = ?`）或 2 位数乘法（如 `23 × 45 = ?`）。
- 每题限时 60 秒，答对得 1 分，答错不扣分，该题作废进入下一题。
- 共 10 题，结束后比较总分，高者胜；同分则平局。
